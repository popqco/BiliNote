# 微信公众号 / 视频号支持（2026-10-24）

## 能力边界

| 平台 | 链接格式 | 是否需要登录 | 实现方式 |
| --- | --- | --- | --- |
| 微信公众号 | `https://mp.weixin.qq.com/s/...` | 否 | 解析文章 HTML 取标题/封面/视频，Playwright 驱动本机 Edge 打开文章并分片下载 |
| 微信视频号 | `https://weixin.qq.com/sph/...` | 是（腾讯元宝） | 公开预览接口取标题/作者/封面；元宝登录态换 `token/eid`，再取播放地址；必要时 ISAAC64 解密前 128 KiB |

## 公众号

1. 在首页平台选择「公众号」，粘贴文章链接。
2. 生成时会自动启动一次无头 Edge（约多 5–10 秒），点开文章内视频并下载。
3. 文章内嵌的如果是**视频号**内容（页面提示“可扫码前往微信观看”），请改用「视频号」平台粘贴视频号分享链接。

要求 Worker 本机安装 Microsoft Edge 或 Google Chrome。公众号视频不需要 Cookie。

## 视频号

视频号不提供匿名播放地址，必须使用腾讯元宝的登录态换临时播放凭证（开源方案
`ltaoo/wx_channels_download`、`x554960766/wechat-mp-tools` 均采用这个思路）。

首次使用：

1. 打开「设置 → 下载器配置 → 视频号」。
2. 点击「扫码登录元宝」。Worker 本机会弹出一个 Edge 窗口，用微信扫码登录。
3. 状态变为「已登录元宝」后即可解析视频号分享链接。
4. 登录态保存在 `config/downloader.json`，不会上传；失效后重新扫码或手动粘贴
   `yuanbao.tencent.com` 的 Cookie（需包含 `hy_token`）。

远端手机端无法直接触发扫码（登录窗口必须出现在 Worker 本机），请先在本机登录，
之后手机端直接提交视频号链接即可。登录失效时建议重新在原视频号页面播放一次，
或重新扫码。

### 常见问题

- **提示“未配置腾讯元宝 Cookie”**：尚未扫码登录，按上面的步骤登录。
- **提示“元宝登录态已失效”**：重新扫码，或在设置页「清除登录态」后重新登录。
- **扫码窗口没出现**：Worker 本机缺少 Edge/Chrome，或后端没有可用的桌面会话
  （无头 Linux 服务器）；可以在设置页手动粘贴元宝 Cookie。
- **视频号下载失败（CDN 403/超时）**：分享链接可能过期，重新从微信复制分享链接；
  腾讯 CDN 对频繁请求也会限流。
- **公众号下载失败（找不到视频）**：文章可能内嵌视频号、视频已删除，或文章需要
  微信登录才能查看。换用对应平台链接重试。

## 安全与合规

- 公众号链路只使用本机 Edge 的匿名会话，不安装根证书、不做 HTTPS 中间人。
- 视频号链路只读取元宝登录 Cookie，不读取微信客户端的任何本地凭据；Cookie 仅保存
  在 Worker 本机，不会回传前端或上传第三方。
- 请只下载你有权保存的内容，并遵守平台条款与当地法律。
