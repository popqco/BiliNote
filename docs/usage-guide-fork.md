# Fork 增强功能使用指南

> 上游基础功能（提交链接生成笔记、模型/转写/下载配置、AI 问答、思维导图、自动化）的通用
> 说明见 README 与 [docs/automation.md](./automation.md)。本文只讲 **fork 新增/增强** 的
> 部分怎么用，按「日常一条龙」的顺序走一遍。

## 1. 生成一篇笔记（桌面端）

1. 首页左侧表单：粘贴 B 站 / YouTube / 抖音 / 小红书 / 本地视频来源，选格式、风格、清晰度，
   按需开「截图」「视频理解」；**复制视频链接后切回窗口会自动弹窗回填**（剪贴板监控，
   「设置 → 通用 → 剪贴板轮询识别」可改成后台定时读取或关闭）。
2. 点生成，进度条四步走；总结阶段卡片会实时显示当前策略
   （「正在调用模型总结…」「上游不稳定，正在用「减帧」策略重试」）——上游不稳时自动降级，
   25 分钟总死线兜底，不会无声卡死。
3. 完成后自动跳到笔记。

## 2. 阅读体验（fork 重点）

**滚动**（「设置 → 通用 → 阅读区平滑滚动」，默认开启）：

- **滚轮**：连贯缓动，没有一格一顿的刻度感；
- **按住左键拖动**：内容 1:1 跟着鼠标走（像手机抓着屏幕拖），**松手带惯性滑行**——
  滑行初速=松手瞬间手速，摩擦衰减自然停下；滑行中再按住即停；
- **Shift + 拖动**：还是原来的文字选择（选中后复制）；无位移的点击不受影响
  （链接、按钮、图片缩放照常）；
- **手感三档**：跟手（快停）/ 适中（默认，滑半屏左右）/ 动量（接近手机松手滑行），
  切换即时生效，建议逐档试一遍选定；
- 只作用桌面端的笔记正文与原文面板；手机端触摸滑动本来就是原生惯性。

**其他阅读功能**：顶部工具栏可复制、导出（PDF / Word / 长图 / 摘要海报）、切换思维导图
（支持主题与 SVG 导出）、「隐藏截图」一键纯文字模式（导出仍含截图）、打开「原文参照」
对照转写稿。

**AI 问答**：侧边/全屏问答；回复里的引用徽章点击即跳到正文对应章节（黄色高亮 2 秒），
带时间戳的引用会同时定位原文面板的对应片段。

## 3. 历史

- 同一个视频只保留一张卡（视频级去重），重复生成会合并进同卡多版本；
- 失败卡片会显示失败原因摘要；
- 点开老笔记，新建表单自动回显它当时的生成参数。

## 4. 自动化（稍后再看 → 自动笔记 → 微信/邮件推送）

设置 → 自动化：开关、频率、范围、每轮上限、生成配置、WxPusher/SMTP 推送。
完整教程见 [automation.md](./automation.md)。fork 增强的行为：

- 每轮开始前先做 ffmpeg 预检（视频理解开着但 ffmpeg 不可用时整轮跳过并说明）；
- 任务失败进入 30 分钟冷却，不会每轮重提同一故障 + 轰炸通知；
- 多 P 视频只总结一次（P2 不会被当成新视频反复跑）；
- 「立即运行一轮」右侧面板能看到每个视频的提交/跳过原因。

## 5. 手机上用（Viewer）

桌面端开着就是 Worker；手机连同一 Tailscale 网络后浏览器打开
`http://<桌面机IP>:8483/`，用 token 配对即可提交任务、看笔记、查问答。
配对步骤与远控开关说明见 [worker-viewer-deploy.md](./worker-viewer-deploy.md)。

## 6. 出问题了先看哪

| 现象 | 去哪看 |
| --- | --- |
| 启动时红/琥珀横幅 | 横幅文案会点名原因；再看 `D:\Program Files\BiliNote\logs\app.log` |
| 笔记卡片失败红字 | 卡片上有原因摘要；转写类多为 Cookie 过期或音频超限（已自适应压缩） |
| 自动化某轮没跑 | 设置 → 自动化 → 最近一轮面板看跳过原因（冷却中/超出上限/ffmpeg 缺失） |
| 桌面端整体异常 | 任务栏退出应用重开；仍异常按 [deploy-windows-installed.md](./deploy-windows-installed.md) 第 4 节坑清单排查 |
